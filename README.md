📈 Google Search Trends Analysis Using Python
📌 Project Overview
This project uses Python and the PyTrends library to analyze Google Search trends across the world. It demonstrates how to extract, visualize, and interpret real-time search interest data for various keywords, enabling data-driven insights into public interest and online behavior.

Google processes over 8.5 billion searches per day, making it a rich source for understanding trends in:

🛒 Market demand

📰 News & media interest

📊 Political forecasting

🔍 Keyword research & SEO

By leveraging Google Trends data, this project helps uncover what people are searching, where they’re searching from, and how interest changes over time.

🛠 Tools & Libraries Used
Python

PyTrends – unofficial API for Google Trends

pandas – data manipulation

matplotlib & seaborn – static plotting

plotly – interactive world map visualization

🔍 Key Features & Analysis Performed
Dynamic Keyword Input

You can analyze any search term simply by changing the keyword in the script.

Top 15 Countries by Search Interest

Visualized using a bar chart and a choropleth world map (using Plotly).

Search Interest Over Time

Line chart showing how keyword interest evolves month to month.

Keyword Comparison

Compare search interest for multiple keywords like "cloud computing", "data science", and "machine learning" in one plot.
